# Ruby Hub website

Plain HTML/CSS/JS. No build step. Works on GitHub Pages.

1. Upload every file here to a GitHub repo root (keep `.nojekyll`).
2. Settings > Pages > Deploy from a branch > main / root.
3. Add scripts in `scripts.js` (the list is empty on purpose). Set your Discord link there too.
4. Replace `icon.png` with a larger copy of your logo if you have one.
5. Search `terms.html` and `privacy.html` for `[` and fill in every placeholder.
   In privacy.html section 2, delete anything you don't log and add anything you do.
